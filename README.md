# OpenMerchant plugins

Plugins and connector configuration for using OpenMerchant from AI assistants and coding
agents: Claude (connectors and plugins), ChatGPT and Codex (plugins), and any client that
speaks the Model Context Protocol.

The first plugins are being prepared in OpenMerchant's main codebase and will be published
here. Until they land, see [openmerchant.dev](https://openmerchant.dev) for the product, and
the [Pay vendors developer page](https://openmerchant.dev/pay-vendors/developers) for the
API and MCP server.

## Security

Report security issues to security@openmerchant.dev.
